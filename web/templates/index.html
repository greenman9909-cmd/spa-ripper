How SPA-Ripper works

Three-phase pipeline — fetch, parse, serve.

1. Fetch & parse

Loads the root shell, extracts all <script>, <link>, and <img> tags, then recursively discovers assets referenced inside JS string literals.

2. Download & cache

All assets are downloaded concurrently and written to disk with their original path structure. CSS url() declarations are followed recursively for fonts and images.

3. Serve locally

A built-in dev server handles SPA route fallback, reverse-proxies /api/* to the real origin, and auto-fetches any missing chunks on first request.
