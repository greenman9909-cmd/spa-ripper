Frequently asked questions

Is this the actual Firecrawl website?

No. This is an original frontend implementation inspired by Firecrawl's clean developer-tool layout and interaction rhythm.

Does the playground make real network requests?

No. The playground is a frontend interaction demo. Connect it to your own scrape or search API to make it live.

Can this move into Next.js?

Yes. The page is structured in isolated sections that can be converted into React components with minimal restructuring.

Does it support dark mode?

Yes. The page follows the operating system preference while keeping the same accent, spacing, and hierarchy.
